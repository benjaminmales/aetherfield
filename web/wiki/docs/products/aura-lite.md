# Aura Lite

:::tip[Coming soon!]
Aura Lite is designed and being quoted for production. It isn't available for testing yet: try the system today with
**[Aura Tag](/products/aura-tag)** and **[Aura Link](/products/aura-link)**, which use the same
radio, commands and API. Specifications below are from the board design;
performance figures will be published once measured.
:::

<div className="soon-body">


The volume wearable: one RGB light, an accelerometer and a coin cell, at a
cost that works for giveaways and very large crowds.

## Specifications

<div className="spec">

| | |
|---|---|
| Radio | IEEE 802.15.4, 2.4 GHz, Aetherfield protocol v2 |
| Processor | Nordic nRF54L05 |
| Antenna | Ceramic chip antenna |
| Light | 1× RGB LED (5050) |
| Motion | 3-axis accelerometer (MEMSIC MC3630) |
| Power | CR2032 coin cell, not rechargeable |
| Battery life | To be measured |
| Radio range | To be measured |

</div>

See [Aura One](/products/aura-one#compared-with-aura-lite) for a side-by-side comparison.

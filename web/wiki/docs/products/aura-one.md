The show wristband: a bright, colourful light on every wrist, a motion sensor
that turns gestures into events, and a rechargeable battery for multi-day events.

## Specifications

<div className="spec">

| | |
|---|---|
| Radio | IEEE 802.15.4, 2.4 GHz, Aetherfield protocol v2 |
| Processor | Nordic nRF54L05 |
| Antenna | Ceramic chip antenna |
| Light | 4× full-colour RGB LEDs on a dedicated LED driver (TI LP5012), plus 3 indicator LEDs |
| Motion | 6-axis IMU, accelerometer and gyroscope (ST LSM6DSRX) |
| Power | Rechargeable lithium-polymer cell, USB-C charging |
| Battery capacity | To be confirmed |
| Battery life | To be measured |
| Radio range | To be measured |

</div>

## What it will do

- Every colour, animation and brightness command, synchronised across the crowd
- Gesture events (hand raise, clap) from on-device machine learning, as
  proven on the Aetherfield development band
- Presence and zone, like every Aura device
- Battery level and charging state in the API

## Compared with Aura Lite

| | Aura One | Aura Lite |
|---|---|---|
| Light | 4× RGB, full dimming | 1× RGB |
| Motion | 6-axis IMU (gestures) | Accelerometer (taps, movement) |
| Power | Rechargeable | Coin cell |
| Best for | Shows, repeat use, multi-day events | Giveaways, single-day events, large volumes |

</div>
